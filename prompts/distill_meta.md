# 元知识蒸馏 Prompt（跨来源关联）

请从这本笔记本中提炼"元知识"——即关于这些知识本身的规律。

## 分析维度

### 1. 来源结构分析
- 笔记本包含哪些类型的来源？（论文/博客/书籍/代码/文档）
- 各来源的互补关系是什么？（理论↔实践、框架↔工具、正交↔递进）
- 有哪些来源相互矛盾？如何解决？

### 2. 知识层次分析
- 这个领域的基础概念（新手必知）
- 这个领域的主流范式（从业者共识）
- 这个领域的前沿方向（发展趋势）
- 这个领域的常见误区（踩坑警示）

### 3. 能力图谱
基于所有来源，生成一张"技能地图"：
```
基础层 → 进阶层 → 专家层
  ↓         ↓         ↓
 {技能A}   {技能B}   {技能C}
  ↓         ↓         ↓
 {工具X}   {工具Y}   {工具Z}
```

### 4. 学习路径建议
- 新手：从哪个来源开始？
- 有基础：从哪个难点切入？
- 有经验：如何建立系统性认知？

## 输出格式
- Markdown，带 ASCII 图示
- 重点标注跨来源关联的知识
- 明确区分"已验证"和"推测"
